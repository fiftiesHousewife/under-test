# Self-application

The toolkit is its own first adopter. This folder is what an organisation repo would hold, for the toolkit project
itself: its [organisation profile](organisation-profile.yaml), and (to come) its records of which
[decision guides](../decision-guides/README.md) it accepts, narrows or replaces for its own code and lessons.
CI will install the toolkit into scratch repos from here to prove the adoption steps work.

See [The toolkit applies itself: this repo is its own first adopter](../docs/decisions/README.md).
