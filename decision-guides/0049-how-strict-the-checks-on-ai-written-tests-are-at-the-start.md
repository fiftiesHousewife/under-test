# How strict the checks on AI-written tests are at the start

**Decided by:** Test Quality Lead · **Status:** proposed (open)

*This is a decision guide for adopting organisations. Each organisation accepts, narrows or replaces it in its own organisation repo.*

## Context and Problem Statement

A strict start is slow; a lenient start lets weak tests in.

## Considered Options

* **All five checks block from day one**  
  Slow start; every kept test can be trusted
* **The coverage-or-bug check only reported for the first quarter**  
  More tests quickly; some weak ones get in

## Decision Outcome

Not yet chosen. The options are below. Open.

### Consequences

* Acceptance check settings.
