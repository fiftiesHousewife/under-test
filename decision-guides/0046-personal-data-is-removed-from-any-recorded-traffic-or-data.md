# Personal data is removed from any recorded traffic or data

**Decided by:** Security and Platform Owner (can veto) · **Status:** proposed

*This is a decision guide for adopting organisations. Each organisation accepts, narrows or replaces it in its own organisation repo.*

## Context and Problem Statement

Recorded traffic and copied data can contain customers' personal data.

## Considered Options

* **Removing personal data is a required step before anything recorded is committed or shared**  
  Protects customers
* **Left to each team**  
  Inconsistent; risky

## Decision Outcome

Proposed: the first option. Seed data for shared test kits is synthetic.

### Consequences

* Shared test kit and recorded-response lessons include the step.
