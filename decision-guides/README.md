# Decision guides

Guides for organisations adopting the toolkit: one small decision per guide, with the options, what follows from each, and the toolkit's recommendation. Each names the engagement role that decides.
An organisation accepts, narrows or replaces each guide in its own private organisation repo, and tracks each open guide as a decision item in its own issue tracker (see [the programme backlog template](../templates/programme-backlog.yaml)).
Decisions about the toolkit itself are in [docs/decisions/](../docs/decisions/README.md). Words follow [GLOSSARY.md](../GLOSSARY.md). The index below is generated from the records by `./gradlew buildDecisionIndexes`.
