# Toolkit decisions

Decisions about the toolkit itself: how it is built, organised, licensed and published, and how organisations adopt it. Made by the toolkit's maintainers, in [MADR](https://adr.github.io/madr/) form, one small decision per record.
For the decision guides the toolkit provides to adopting organisations, see [decision-guides/](../../decision-guides/README.md).
Numbers follow reading order until a record is accepted; after that a number never changes. Words follow [GLOSSARY.md](../../GLOSSARY.md). The index below is generated from the records by `./gradlew buildDecisionIndexes`.
