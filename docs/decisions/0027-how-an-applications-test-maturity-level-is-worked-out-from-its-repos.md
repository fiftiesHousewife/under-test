# How an application's test maturity level is worked out from its repos

**Decided by:** Test Quality Lead, approved by the Steering Group · **Status:** proposed (open)

## Context and Problem Statement

An application spans several repos. Key user journeys pass through more than one.

## Considered Options

* **The lowest level of any repo on a key user journey**  
  Strict and honest
* **A weighted mix**  
  Rewards progress, but can hide an untested step in a journey

## Decision Outcome

Not yet chosen. The options are below. Open.

### Consequences

* Summaries by organisation unit (summaries by organisation unit).
