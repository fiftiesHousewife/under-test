# Repos no longer deployed or changed get a retirement review, not a testing plan

**Decided by:** Engagement Lead, with the Programme Sponsor · **Status:** proposed

## Context and Problem Statement

Planning tests for code nobody runs wastes subject-matter expert time, the scarcest resource.

## Considered Options

* **Retirement review**  
  Shrinks the scope
* **Plan them anyway**  
  Effort on code nobody runs

## Decision Outcome

Proposed: retirement review.

### Consequences

* Repo inventory tool (the repo inventory tool).
