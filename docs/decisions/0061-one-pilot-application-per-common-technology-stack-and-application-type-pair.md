# One pilot application per common technology stack and application type pair

**Decided by:** Engagement Lead, with the Programme Sponsor · **Status:** proposed

## Context and Problem Statement

The default testing approach for each kind of repo should be learned on a real application before being reused.

## Considered Options

* **One pilot per common pair, treated by hand; what we learn becomes the testing guides**  
  Guides grounded in real code
* **Write guides from theory**  
  Untested advice

## Decision Outcome

Proposed: the first option. Pilots chosen so the first batch covers the pairs with the most repos.

### Consequences

* choosing pilot applications, assessing pilot applications by hand, writing the testing guides.
