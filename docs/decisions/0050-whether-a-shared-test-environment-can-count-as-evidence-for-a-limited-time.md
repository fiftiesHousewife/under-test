# Whether a shared test environment can count as evidence for a limited time

**Decided by:** Test Quality Lead, approved by the Steering Group · **Status:** proposed (open)

## Context and Problem Statement

Some systems can't be stood in for quickly. A shared test environment could bridge the gap.

## Considered Options

* **Allowed, with an expiry date recorded in the assessment file**  
  Faster progress to level 2; brings flaky tests and data risk
* **Not allowed**  
  Repos with hard-to-replace systems stall

## Decision Outcome

Not yet chosen. The options are below. Open.

### Consequences

* Evidence rules (decision 0024).
